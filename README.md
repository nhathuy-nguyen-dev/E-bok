# Bokro – klikkbare skisser

Prototyper av skissene for å vise ventetid på en reservert lydbok.
Laget med vanlig HTML, CSS og JavaScript, uten rammeverk.

## Slik åpner du dem
Åpne `index.html` i nettleseren (dobbeltklikk på fila). Du trenger ingen server.

## Sider
| Fil | Innhold |
|---|---|
| `index.html` | Oversikt med lenker |
| `skisser.html` | Skisse A–I, alle klikkbare |
| `versjon1.html` | Versjon 1 i tre situasjoner (normal, forlenget lån, usikkert anslag) |
| `versjon2.html` | Versjon 2 i de samme tre situasjonene |

## Mapper
- `css/felles.css` – stil som alle sidene bruker
- `js/felles.js` – små hjelpefunksjoner (melding nederst, klokkeslett, situasjonsvelger)
- `js/skisser.js`, `js/versjon1.js`, `js/versjon2.js` – logikken for hver side
- `bilder/` – originalskissene (PNG)
